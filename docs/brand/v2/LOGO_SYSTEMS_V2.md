## 1) Bridge Span

### Positioning

Best when you want the brand to feel enterprise-ready, dependable, and operationally stable.

### Visual logic

- Bridge arch = structural trust
- Center roadway = uptime and movement
- Four outer nodes + hub = platform coordinates all actors

### Motion cue

Draw bridge arch first, then pulse hub and route a single service token from node to hub.

## 2) Route Node

### Positioning

Best when you want to emphasize algorithmic matching, dispatch intelligence, and network throughput.

### Visual logic

- Central hex hub = routing engine
- Radial links = connected marketplace participants
- Direction markers = guided workflow and dispatch confidence

### Motion cue

Stagger radial nodes in; animate one highlighted route path to indicate successful match.

## 3) Pitstop Link

### Positioning

Best when you want to emphasize service velocity and practical, boots-on-the-ground execution.

### Visual logic

- Interlocking links = platform-mediated trust handoff
- Center span = bridge from request to repair
- Speed bars = reduced downtime

### Motion cue

Slide two links together, lock them, then sweep speed bars to indicate truck back on road.

## Recommendation Logic

If your first launch audience is:

1. Fleets and enterprise operators: start with `Bridge Span`.
2. Mixed marketplace growth and matching quality narrative: start with `Route Node`.
3. Driver-first and urgent roadside service narrative: start with `Pitstop Link`.
